---
name: Erasmus+ mobile PWA scope
description: Product boundary between the mobile app and desktop visitor landing.
---

The Erasmus+ mobile experience is a functional PWA for users, not a promotional landing page. Public visitor promotion and galleries belong on the desktop site; the mobile app should route people to sign-in or their workspace.

**Why:** The user explicitly wants the mobile app to be functional rather than promotional.

**How to apply:** Keep desktop visitor content out of the mobile PWA. Use its root route for access or the authenticated workspace.
