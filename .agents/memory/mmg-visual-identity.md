---
name: MMG visual identity
description: The user's standing color constraint for visual changes to the Erasmus+ MMG app.
---

When restyling the Erasmus+ MMG application, preserve its original color palette.

**Why:** The user explicitly asked that the interface resemble their reference while keeping the application's original colors.

**How to apply:** Treat layout, spacing, and navigation as flexible; retain the MMG navy, blue, teal, and light surfaces unless the user asks to change them.
