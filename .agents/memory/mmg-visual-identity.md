name: MMG visual identity
description: The user's standing color constraint for visual changes to the Erasmus+ MMG app.
---

When restyling the Erasmus+ MMG application, preserve its original color palette and use the logo supplied by the user in the header, PDFs, and as the favicon. Keep the header fixed and start the content area's right-side scrollbar immediately below it. Hide the sidebar on the visitor, login, registration, and personal-data-protection pages. The internal navigation sidebar should stay narrow when collapsed, open on hover, and have a floating pin to keep it open.

**Why:** The user explicitly asked to retain the original colors, use the supplied logo in the brand, PDFs, and favicon, keep the header and scrollbar aligned, and hide side navigation on public and privacy pages.

**How to apply:** Treat layout and spacing as flexible; retain the MMG navy, blue, teal, and light surfaces. Use the supplied logo files in the header, generated PDFs, and browser/PWA icon references. Keep the floating pin keyboard- and touch-accessible, show labels when the sidebar is open, and keep page scrolling inside the area beneath the header.
